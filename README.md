# MindMap Basic

A local mind-mapping app built with plain HTML, CSS, and JavaScript. No server, package installation, or account is required: open `index.html` in a modern browser.

## Features

- Hierarchical and free-form map modes
- Nodes with titles, notes, colors and images
- Links between nodes with direction, color and width
- Drag nodes, pan and zoom, fit to map, automatic layout
- Resizable nodes, node and map appearance settings, background styles
- 3D view
- Search with match counter
- Pinch-to-zoom on touch screens
- Warning before closing the tab or opening a file over unsaved changes
- Open and save maps as JSON
- English, Ukrainian and Russian interface

## Keyboard Shortcuts

- `Enter` — add a child node in hierarchical mode or an independent node in free-form mode.
- `F2` — edit the selected node's title.
- `Delete` — delete the selected node and its subtree in hierarchical mode; in free-form mode, delete only the node and its links.
- `Esc` — cancel link creation, close the settings panel.
- Search: `Enter` / `Shift+Enter` — next / previous match.
- `Ctrl+S` / `⌘S` — save JSON.
- `Ctrl+K` / `⌘K` — focus search.
